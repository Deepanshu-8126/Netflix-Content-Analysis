# Netflix Content Analysis

## Project Overview

Analysis of Netflix Movies and TV Shows using:

- Excel
- SQL
- Python
- Power BI

## Dataset

Netflix Movies and TV Shows Dataset

## Tools Used

- Excel
- MySQL
- Python
- Pandas
- Matplotlib
- Power BI

## Key Insights

- Movies dominate Netflix catalog.
- United States contributes most content.
- Content growth accelerated after 2015.
- TV-MA is the most common rating.
- Top directors contribute significant content volume.
